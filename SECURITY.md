# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Velto, please do NOT file a public issue. Instead, send an email describing the vulnerability.

We will acknowledge your report within 48 hours and work with you to release a patch promptly.
